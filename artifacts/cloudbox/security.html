Security lab

Encrypt and reconstruct files locally with AES-256-GCM, then retrieve an encrypted package over HTTPS when a CloudFront object is available. Processing requires a secure browser context.

Educational prototype · secure context required

Browser cryptography APIs are generally available only on HTTPS or localhost. This interface is not an upload service and does not claim an authenticated API, key recovery, or a security audit.

Key handling warningThe encryption key is downloaded separately. Anyone with both the encrypted package and its key can decrypt the file. Keep the key private and never upload it to a public website or commit it to Git.

Use this carefully

Encryption protects content, not every risk.

Keep key and package separate

A public package link plus a publicly available key defeats file confidentiality. Share keys through an appropriate separate channel.

Authentication failures matter

If any GCM tag check fails, treat the package as invalid. Do not ignore a failed block or offer partial plaintext as a completed result.

Browser endpoint still matters

Malware, compromised extensions, shared devices, and memory exposure can undermine client-side protections.
