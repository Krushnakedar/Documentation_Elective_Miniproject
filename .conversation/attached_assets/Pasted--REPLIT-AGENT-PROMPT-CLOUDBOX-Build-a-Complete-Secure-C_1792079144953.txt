### Encryption requirements

Implement actual cryptography with the browser's Web Crypto API.

1. Generate a fresh AES-GCM 256-bit key using `crypto.subtle.generateKey()`.
2. Use `crypto.getRandomValues()` to generate a unique 12-byte IV for every encrypted block.
3. Split the input file into independently encrypted blocks.
4. Encrypt every block with AES-GCM authenticated encryption.
5. Encode IVs and ciphertext safely using Base64.
6. Preserve block order using explicit indexes.
7. Store original filename, file size, block size, block count, format version, algorithm, IV, and ciphertext in the package.
8. Export the raw encryption key into a separate downloadable key file.
9. Keep the key out of the encrypted package.
10. Import the separate key during decryption.
11. Decrypt blocks in their correct order.
12. Reconstruct the original file using a Blob.
13. Verify the reconstructed file size.
14. Handle empty files.
15. Reject malformed package structures and invalid metadata.
16. Reject invalid key lengths and malformed Base64 values.
17. Reject duplicate or missing block indexes.
18. Reject inconsistent block counts and sizes.
19. Detect authentication failures caused by incorrect keys or modified ciphertext.
20. Sanitize downloaded filenames.
21. Release temporary object URLs safely.
22. Disable conflicting controls while processing.
23. Show accessible progress and error messages.

Use a versioned JSON package format with:

- `format`
- `version`
- `algorithm`
- `originalName`
- `originalSize`
- `blockSize`
- `blockCount`
- `chunks`

Each chunk should include an index, IV, and encrypted data.

Do not use inefficient spread operations on large arrays.

Validate the file size before reading its contents. Enforce sensible bounds on block size, package size, chunk count, and metadata.

The default maximum file size is 100 MiB. Document the memory limitations of browser-based processing.

Never log the encryption key, plaintext data, or sensitive content.

### Key security
